# University submission checklist

Complete this list before submitting the individual Group Dynamics and Communication assignment. A functioning local website alone is not a completed submission.

- [ ] Professional identity, education dates, current study year, skills, and curricular internship objective are accurate.
- [ ] All public-facing content is in English and uses a coherent visual identity.
- [ ] The real, updated CV is saved as `public/cv.pdf`.
- [ ] The CV opens and downloads correctly; the downloaded file has been checked.
- [ ] The real personal introduction is saved as `public/videos/pitch.mp4`.
- [ ] The actual video is no longer than 60 seconds and has clear, audible speech.
- [ ] Video playback and controls work on desktop and mobile; accurate English captions have been added where possible.
- [ ] The CV, spoken introduction, and website describe the same authentic background and skills.
- [ ] Only verified projects and exact, verified social/repository URLs are included.
- [ ] Navigation, mobile menu, keyboard focus, and the contact email work.
- [ ] Layouts have been checked at mobile, tablet, and desktop sizes, with no horizontal overflow.
- [ ] `npm run build` succeeds after the final content and media changes.
- [ ] `npm run preview` has been used to review the final production build.
- [ ] Publication has been deliberately authorised and completed.
- [ ] The public URL opens without signing in, including in a private browser window.
- [ ] CV viewing/downloading and video playback have been checked at that public URL.
- [ ] The verified public URL is included in the assignment submission.
