# Ricardo Dias Guilherme | Developer Portfolio

This personal portfolio presents my Computer Science studies at the University Polytechnic of Beja and my goal of completing a curricular internship. It includes my Task Management REST API project and CV.

Built with React, JavaScript (JSX), Vite, and CSS.

## Local development

Requires Node.js 22.12 or later and npm.

```sh
npm install
npm run dev
```

Open the local address printed by Vite. If PowerShell blocks `npm`, use `npm.cmd` in the commands.

## Production build

```sh
npm run build
npm run preview
```

The build generates the static site in `dist/`. Use the preview address printed by Vite to check the production build locally.

For Vercel, use `npm run build` as the build command and `dist` as the output directory.

Portfolio content is in `src/data/portfolio.js`. The photo and CV are in `public/`.
